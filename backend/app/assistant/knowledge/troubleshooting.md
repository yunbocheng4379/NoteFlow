# NoteFlow 常见问题

## 视频无法下载

先确认视频链接仍然有效，并检查平台是否需要 Cookie。Bilibili、抖音等平台的登录态或访问限制可能导致下载失败，可以根据任务提示到 Cookie 或下载设置中补充配置后再重试。

## 转写或生成失败

先打开“任务列表”查看失败原因。如果提示 FFmpeg 不可用，需要检查部署环境是否安装并正确配置 FFmpeg；如果提示转写模型未准备好，需要到转写设置中下载或选择可用的转写方案。

## 模型不可用

到管理员的模型设置中确认供应商 API 地址、API Key 和模型名称正确，并确认至少有一个模型处于启用状态。模型接口返回限流、余额不足或网络错误时，需要根据供应商状态稍后重试。

## 电力不足

AI 笔记生成和部分 AI 问答会按照系统配置消耗电力。可以打开“账单与额度”查看剩余电力、充值或会员状态；如果是产品客服本身的问答，第一版不扣减用户电力。
