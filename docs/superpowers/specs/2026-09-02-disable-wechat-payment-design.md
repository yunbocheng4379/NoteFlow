# 微信支付暂不支持状态设计

## 目标

在微信支付尚未正式可用期间，保留支付方式入口用于告知用户功能规划，但阻止用户切换到微信支付或创建微信支付订单。

## 交互方案

- 支付弹窗继续展示“微信支付”选项。
- 微信支付选项显示不可用的视觉状态。
- 用户点击微信支付时，显示“微信支付暂不支持，功能即将上线，请先使用支付宝支付”。
- 点击后不改变当前选中的支付宝支付方式。
- “去支付”按钮只允许按支付宝流程继续。
- 已有支付宝支付流程、订单轮询和支付成功处理不变。

## 实现范围

修改 `NoteFlow_frontend/src/pages/UpgradePage/PayDialog.tsx`：

- 为支付方式定义增加可用状态信息。
- 对微信支付入口增加点击拦截和不可用样式。
- 在创建订单前增加微信支付保护，避免前端误调用微信支付下单。
- 保留真实支付和 Mock 支付的现有结构，避免影响支付宝及历史订单展示。

## 测试与验证

- 增加针对支付方式选择行为的测试：点击微信支付后显示提示且仍保持支付宝选中。
- 增加针对订单创建保护的测试：微信支付不可触发创建订单回调。
- 运行前端 lint 和 production build。

## 非目标

- 不删除后端微信支付代码。
- 不修改微信支付配置或订单数据库结构。
- 不实现微信支付上线逻辑。
