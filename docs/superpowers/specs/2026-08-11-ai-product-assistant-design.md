# NoteFlow AI 产品客服“小流”设计规格

## 1. 背景与目标

NoteFlow 已经具备视频转写、结构化笔记生成、知识库检索问答和模型配置能力，但用户在第一次使用时仍需要自行理解入口、流程和错误提示。本功能在登录后的主工作台右下角提供一个可随时打开的 AI 产品向导“小流”，围绕 NoteFlow 自身能力回答产品问题，并在回答中给出可追溯的产品文档来源。

本次目标：

- 只在登录后的受保护工作台显示客服入口，登录页、介绍页和其它公开页面不显示。
- 点击右下角角色入口后，在右下角打开一个可关闭的问答面板。
- 支持中文产品问答、快捷问题、流式输出、基础 Markdown 和产品文档引用。
- 用独立的产品帮助 RAG 通道回答 NoteFlow 相关问题，不与用户的视频笔记或知识库会话混用。
- 角色图片作为独立资源接入，后续可以替换，不让 UI 代码依赖具体画风。

## 2. 非目标

- 第一版不回答泛领域知识、医疗/法律/财务等非产品问题。
- 第一版不代替现有的“针对笔记内容提问”或“知识库问答”。涉及用户笔记内容时，客服只负责引导用户去对应功能。
- 第一版不新增管理员文档编辑后台；产品文档以版本化 Markdown 文件维护。
- 第一版不在登录页、产品介绍页、浏览器扩展或桌面壳之外的公开页面显示。
- 第一版不扣减用户的电力余额。客服属于产品帮助能力，调用模型的成本由系统侧承担；后续如需限额可单独增加客服频控或后台策略。

## 3. 视觉与交互设计

### 3.1 角色设定

- 名称：小流（NoteFlow 的产品向导）。
- 气质：温柔学姐 + 轻未来感；亲切、可靠、耐心，不做夸张卖萌或强营销。
- 形象：奶油白短发、青绿色瞳色、浅珊瑚发夹、奶油白针织外套、深青绿色内搭，胸前有抽象的流线形徽章。
- 状态：静止时轻微呼吸；回答中显示“整理资料中…”或小幅高光变化；尊重 `prefers-reduced-motion`。

### 3.2 色彩与尺寸

- 主色：`#167A6E`。
- 薄荷背景：`#E6F7F5`。
- 奶油底色：`#FFF9F5`。
- 珊瑚强调：`#FF9B8A`。
- 正文墨蓝：`#243447`。
- 入口：桌面端 64px，移动端 56px；距离右侧和底部 20–24px。
- 面板：桌面端宽 360px、高 520px；最大高度不超过视口高度减 32px；移动端宽度为 `calc(100vw - 24px)`，从右下角贴边弹出。

### 3.3 面板结构

1. 顶部：小流头像、名称“ 小流 · NoteFlow 向导”、在线状态、关闭按钮。
2. 空态：角色半身图、欢迎语、四个快捷问题。
3. 消息区：用户消息右对齐，客服消息左对齐；客服回答支持 Markdown；回答来源以“参考产品文档”折叠展示。
4. 输入区：多行输入框，Enter 发送，Shift+Enter 换行；发送中禁用重复提交。
5. 状态：加载、回答中、失败重试、无模型配置、无权限均提供可读的中文提示。

首屏欢迎语：

> 嗨，我是小流。把视频变成清晰笔记、在笔记里继续追问，就是 NoteFlow 最擅长的事。你想先了解哪一步？

快捷问题：

- NoteFlow 是做什么的？
- 怎么把视频变成笔记？
- 知识库问答怎么用？
- 为什么生成失败？

## 4. 技术架构

### 4.1 前端

新增一个工作台级组件 `WorkspaceAssistant`，在 `Index` 中与 `<Outlet />` 同级挂载。这样它会覆盖首页、任务、合集、知识库等受保护子路由，并在子路由切换时保留打开状态和会话状态；由于 `Index` 只在受保护布局内渲染，公开页面不会加载它。

组件拆分：

- `WorkspaceAssistant.tsx`：入口按钮、面板开关、响应式定位、焦点和无障碍属性。
- `AssistantPanel.tsx`：欢迎空态、消息列表、快捷问题、输入、流式状态和来源折叠。
- `services/assistant.ts`：调用 `/assistant/ask_stream` 并解析 SSE。
- `store/assistantStore`：保存当前工作台会话消息；只保留最近 20 轮，避免本地状态无限增长。
- `assets/assistant/xiaoliu.png`：透明角色素材，可独立替换。

### 4.2 后端

新增独立的产品客服模块，不复用用户笔记的 task collection：

- `backend/app/assistant/knowledge/*.md`：产品帮助文档，按主题拆分并版本化。
- `backend/app/services/product_assistant_store.py`：读取 Markdown、按 H2/H3 切分、写入/查询独立 Chroma collection。
- `backend/app/services/product_assistant_service.py`：产品文档检索、提示词、模型调用、来源格式化。
- `backend/app/routers/assistant.py`：鉴权、参数校验和 SSE 响应。
- `backend/tests/test_product_assistant.py`：文档切块、范围约束和接口辅助逻辑测试。

产品客服 Chroma collection 使用固定名称 `noteflow_product_assistant`，索引目录继续复用 `VECTOR_DB_DIR`。索引采用现有的 `LocalHashEmbeddingFunction`，不引入新的线上 embedding 下载。首次问答时按文档指纹懒加载或重建索引，后续请求直接查询。

### 4.3 数据流

```text
点击小流
  -> 输入问题
  -> 前端 POST /assistant/ask_stream
  -> JWT 鉴权 + 长度/历史校验
  -> 产品文档 Chroma 检索 Top-K
  -> 拼接受限系统提示词 + 文档上下文 + 最近历史
  -> 选择当前用户可用的第一个 normal 模型
  -> SSE: sources -> delta* -> done
  -> 前端逐段渲染回答并折叠展示来源
```

## 5. API 设计

### `POST /assistant/ask_stream`

请求：

```json
{
  "question": "NoteFlow 是做什么的？",
  "history": [
    {"role": "user", "content": "我想整理课程视频"},
    {"role": "assistant", "content": "可以把视频链接交给 NoteFlow…"}
  ]
}
```

约束：`question` 去首尾空白后不能为空，最长 1000 个字符；历史只接收 `user` / `assistant`，服务端只使用最近 20 条且单条限制长度。

SSE 事件：

```json
{"type":"sources","sources":[{"title":"快速开始","section_title":"视频转笔记","text":"…"}]}
{"type":"delta","content":"NoteFlow 是…"}
{"type":"done"}
```

失败时返回：

```json
{"type":"error","message":"当前还没有配置可用的 AI 模型，请先到设置中完成配置。"}
```

错误策略：模型未配置、供应商不存在、模型调用失败、文档索引失败均返回用户可理解的中文提示；索引失败不会把异常堆栈暴露给前端；没有召回文档时只允许模型回答“当前产品资料不足”，并引导用户查看相关页面。

## 6. 产品知识文档范围

首批文档覆盖以下事实：

- NoteFlow 是将 Bilibili、YouTube、抖音、快手和本地视频内容转写并生成结构化 Markdown 笔记的 AI 视频笔记系统。
- 支持视频链接和本地上传，可配置转写引擎、模型供应商、笔记风格、截图和原片链接。
- 生成后的笔记可以索引到知识库，进行跨笔记问答并查看引用来源。
- 任务列表、笔记合集、导出、闪记卡、模型配置、电力余额和会员能力的入口与基本用法。
- Cookie、FFmpeg、转写、模型配置和额度不足等常见问题的排查路径。

每个文档块保存 `title`、`section_title`、`source_type=product_doc` 和 `content_hash` 元数据，前端只展示文档标题/章节和截断后的摘要，不暴露内部文件路径。

## 7. 安全与边界

- 接口必须依赖现有 `get_current_user`，未登录请求直接拒绝。
- 不把 provider API Key、数据库信息、内部路径或异常堆栈放入提示词或 SSE。
- 客户端传入的历史只作为普通对话上下文，系统提示词明确要求忽略历史中的越权指令。
- 对问题和历史设置长度限制；后续可在路由层增加按用户/IP 的频率限制。
- 客服不会读取用户私人笔记、转录或账户明细；这类问题必须引导到现有功能入口。

## 8. 验收标准

- 登录后在首页、任务、合集、知识库等受保护页面右下角均能看到入口；公开页面看不到入口。
- 点击入口打开面板，再次点击关闭；刷新前在同一工作台布局内切换路由不会丢失会话。
- 点击四个快捷问题均能发起问答；输入问题可通过 Enter 发送，Shift+Enter 换行。
- 问“NoteFlow 是做什么的？”时，回答必须提到“将视频内容转写并生成结构化笔记”，且来源区域能展示产品文档。
- SSE 回答能逐段显示，加载中不能重复发送；请求失败后可以重试。
- 未配置模型时显示明确提示，而不是空白或未处理异常。
- 移动宽度下不出现横向溢出；键盘焦点可见；开启减少动画时不播放呼吸动画。
- 后端产品助手单测通过，前端 `pnpm lint` 与 `pnpm build` 通过。
