# 笔记风格公开分享提示文案设计

## 目标

修正用户点击“公开分享”后的成功提示，准确表达笔记风格已经提交管理员审核，而不是已经公开上架。

## 变更范围

- 修改 `NoteFlow_frontend/src/pages/SettingPage/NoteStylePage.tsx` 中的公开操作成功提示。
- `val === true` 时显示“已提交给管理员审核，等待审核”。
- `val === false` 时继续显示“已设为私有”。
- 不修改后端接口、审核状态流转、数据库数据或卡片状态展示。

## 验证标准

- 公开操作不再出现“已公开”提示。
- 设为私有仍显示原有提示。
- TypeScript 检查、目标文件 ESLint、生产构建和 `git diff --check` 通过。
